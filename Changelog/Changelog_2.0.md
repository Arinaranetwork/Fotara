# Fotara 2.0 - Local-First Academic Operating System
Released: 2026-10-10   Status: In Progress (Alpha)

## 2.0.0 Alpha - 2026-10-10
- **Space Super-Hierarchy & Schema v20 Migration**: Elevated Fotara into a multi-vault academic operating system. Added SQLite schema v20 with `spaces` table, foreign key cascades on `workspaces.space_id`, default space auto-seeding ("Academic Vault"), and reactive `ActiveSpaceManager`. Integrated interactive `SpaceSwitcherBottomSheet` with top header brand dropdown (`Fotara ▾ [Space Name]`).
- **3-Tier Stealth Privacy System**: Multi-layered protection for sensitive student study notes, personal academic journals, research materials, and exam questions:
  - *Tier 1 (Private Folders)*: Concealed folders revealed via deliberate 2-second pull-down drag gesture on `HomeScreen` folder grid with biometric unlock fallback.
  - *Tier 2 (Ghost Workspaces)*: Hidden study workspaces toggled via 1.5-second long-press on persistent `Home` bottom navigation tab with visual snackbar feedback.
  - *Tier 3 (Stealth Space Vault & .nomedia Shielding)*: Complete academic vaults hidden from view until unlocked via 2-second long-press on header title (`ScreenHeader`), paired with automatic `.nomedia` filesystem shielding to protect study photos from Android MediaScanner and third-party gallery apps.
- **Course Syllabus Weight & Target Exam Grade Evaluator**: University-grade syllabus grade projection engine calculating exact required final exam scores to achieve target letter grades (A, B, C, D). Includes interactive `SyllabusEvaluatorSheet` with dynamic component cards, target percentage slider, and achievable status indicators. Accessible directly from the `HomeScreen` overflow menu.
- **Active Recall Masking & Diagnostic Occlusion Tape**: Interactive diagram self-quizzing tool for anatomy diagrams, chemical equations, mathematical derivations, and vocabulary lists. Features high-contrast accent occlusion tape, tap-to-reveal animations with dashed reveal outlines, and bulk "Reveal All" / "Hide All" quiz study actions.
- **Document Perspective Rectification & Optical Enhancement Filter**: Pure mathematical 3x3 projective homography transformation matrix (`PerspectiveDewarpMatrix`) computing mapping from 4 quadrilateral corners to rectangular bounds without external OpenCV dependencies. Adaptive contrast and shadow suppression filter (`WhiteboardContrastFilter`) converting dimly lit classroom whiteboard photos into crisp study notes.
- **Coursework Archive & Interchange Bundle (.fotara)**: Standardized coursework exchange format packaging notes, photos, documents, and hierarchical metadata into a single `.fotara` ZIP bundle with checksum-verified `manifest.json` and Zip Slip directory traversal protection.
- **Fotara Package Manager & Modular Add-Ons (.fpkg)**: Dynamic on-demand package loader architecture maintaining a lean base APK size under 25 MB while supporting runtime modular add-ons (Real-Time Collab Canvas, Mathematical OCR, Predictive Exam Analytics). Includes cryptographic SHA-256 integrity verification, Just-In-Time interception dialogs (`JitFeatureInterceptionDialog`), and Settings management hub (`PackageManagementHubScreen`) with storage reclamation tracking.
- **Dedicated In-App Friends Study Network**: Privacy-focused peer study network for student contacts. Features `FriendsSettingsCard` strictly positioned between Profile and General in Settings, full-featured `FriendsScreen` with search filtering and user tags (`@handle`), 4-state study presence status indicators (Offline, Studying, In Lecture, Open to Collab), and interactive QR code matrix sharing.
- **Live Collaborative Study Canvas**: Real-time peer study canvas with 6-digit room codes (`FT-XXXX`), low-latency vector stroke synchronization, conflict-free stroke merging, and animated peer cursors (`PeerCursorOverlay`) with student presence badges and session controls bar (`CollabSessionBar`).
